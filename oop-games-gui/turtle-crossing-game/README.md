# 🐢 Turtle Crossing Game

A classic arcade-style road-crossing game built with Python's Turtle graphics module. Players guide a turtle across a busy road while avoiding moving cars and progressing through increasingly difficult levels.

## Features

- Keyboard-controlled turtle movement
- Randomly generated cars with different colors
- Increasing traffic speed as levels progress
- Collision detection between the turtle and cars
- Automatic level progression
- Game-over detection

## Technologies

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)
- Random Module

## How to Run

1. Make sure Python 3 is installed.
2. Navigate to the project directory.
3. Run:

```bash
python main.py
```

No third-party dependencies are required.

## How to Play

1. Press the **Up Arrow (↑)** to move the turtle forward.
2. Avoid colliding with moving cars.
3. Reach the top of the screen to advance to the next level.
4. Each new level increases the speed of the cars.
5. The game ends when the turtle collides with a car.

# Treasure Island

A branching terminal adventure driven by player choices.

## Features

- Nested decision paths
- Multiple endings

## Technologies

Python standard library; terminal input/output, functions, collections, and control flow.

## Installation

```powershell
cd python-fundamentals/treasure-island
python -m venv .venv
```

Use Python 3.10 or newer. On macOS/Linux, the environment interpreter is `.venv/bin/python`.

## Usage

Run from this project directory so relative resource paths resolve correctly:

```powershell
.\.venv\Scripts\python.exe main.py
```

Answer the direction, travel, and door prompts using the displayed words.

## Current limitations

Choices are case-sensitive.
